This is the project I worked on to study for the midterm. It includes a main class BattleSimulator that allows the user to input their character out of mage, fighter, and rogue, each doing specific tasks, and runs combat until the user loses (their character hp is at 0) or wins (enemy hp == 0)
Character class has all the generics and methods each class uses
Fighter has the ability to go into rage after getting hit 3 times and deals extra damage
Mage has a mana bar and can spend 10 mana to heal itself
Rogue can hit a random amount between 3 and 6 and gains dodge points every time it hits for the same amount of damage it does
Enemy can attack and defend
